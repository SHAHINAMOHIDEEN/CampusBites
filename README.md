# Campus Bites – Power BI Dashboard

# Project Overview
Campus Bites is an interactive dashboard developed using Microsoft Power BI to analyze campus canteen sales and business performance.

# Objectives
- Analyze sales and revenue performance.
- Understand customer types and purchasing patterns.
- Identify product performance and sales trends.
- Present insights through interactive data visualizations.

# Tools Used
- Microsoft Power BI
- Power Query for data preparation
- DAX for calculations

# Key Features
- Interactive data visualizations.
- Sales and revenue analysis.
- Customer type analysis.
- Product performance analysis.

# Project File
The Power BI dashboard file ("Project(final).pbix") is available in this repository.

# Conclusion
This project demonstrates the use of Power BI to transform sales data into meaningful visual insights that support data-driven decision-making.
